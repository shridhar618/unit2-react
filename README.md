# React Fundamentals

Coursework examples covering core React concepts, each in its own component file.

## Topics

| Concept | Files |
|---|---|
| Functional and class components | `App_fuctionalComponent.js`, `components/BookClass.jsx`, `components/CounterClass.jsx` |
| Props and composition | `Appprops.js`, `Appcomposing.js`, `ParentFn.js`, `ChildFn.js`, `GreetingFn.js` |
| State | `App_State.js` |
| Event handling | `App_Evant.js`, `Event_countrAdd.js` |
| Dynamic lists and tables | `AppDynamic.js`, `components/BookTable.jsx`, `components/BookRow.jsx` |
| Search and filtering (lifting state up) | `App_Country.js`, `Event_countryFilter.js`, `Event_countryTable.js`, `components/Country*.jsx` |

## Tech stack

React 19 · Create React App · React Testing Library

## Getting started

```bash
npm install
npm start
```

To run a different example, change the component imported in `src/index.js`.
